能做什么

不用一直盯着手机，也不用一直用手

诺伊把「听懂一句话」变成一串可检查的动作，每一步都能在后台屏幕上看见，敏感动作会先停下来问你。

语音唤起，结果念出来

通过系统数字助手入口叫起；个人版另有本地常驻热词，唤醒词可自定义。识别、播报与确认都在本机完成，说话时自动关麦避免自己听自己。

后台屏幕上替你操作

在独立的后台显示区域打开应用、点击、输入、滚动，你的前台屏幕照常用；想看进度随时点开小窗。

任意 App 与网页

按屏幕上的实际画面找按钮，不依赖每个应用的私有接口；内置浏览器里可以直接就当前网页提要求。

敏感动作二次确认

发消息、付款、删除这类动作会先复述并等你确认；半双工语音设计，听的时候不抢话，确认词有明确边界。

免费档自动接力

额度感知路由只使用各家官方公开免费档与你自己的 Key；遇到 429 / 额度耗尽自动冷却切换，到期自愈，不碰来路不明的共享额度。

可验证的更新链路

官网发布版本清单，安装包托管在 GitHub Releases；下载前校验官方域名，下载后校验大小、SHA-256、包名、版本与签名证书。

四道校验

下载前和下载后各有一层，任何一层不过就拒绝安装。

  • 下载地址只允许官网与自有仓库的 HTTPS 附件路径

  • 包名必须等于当前应用，版本必须更新
  • 签名证书必须与已安装版本一致，系统安装器还会再验一次
常见问题

装之前你可能想问

需要 Root 吗？

不需要 Root 也能安装并使用对话、语音问答、网页阅读等能力。部分「替你操作其它 App」的自动化执行能力依赖系统 shell 权限，需要按指南通过无线调试 / USB 调试或设备已提供的 root 通道开启；未开启时 App 会明确提示，不会假装执行成功。

公版能改唤醒词吗？

不能。公版唤醒词固定为「诺伊」，运行时也会拒绝修改；自定义唤醒词与常驻热词是个人版能力。这样公版可以不含常驻麦克风能力，方便对外分发与合规审核。

模型 Key 和额度怎么处理？

Key 由你自己填入并保存在本机。额度路由只使用服务商官方公开的免费档和你自己的 Key，遇到限流或额度耗尽会自动冷却并切换到下一个可用候选，恢复后自愈；不提供、也不使用来路不明的共享额度。

为什么官网和 GitHub 都要用？

官网 noy.127068.xyz 是发布渠道：版本清单、下载页、文档与校验值都在这里。GitHub 仓库 cnwhli/nuoyi 存源码、发布附件与问题反馈。官网暂时不可达时，App 会从仓库里同一份清单的镜像读取版本信息。

这个项目是开源的吗？
