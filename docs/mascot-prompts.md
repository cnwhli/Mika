# 诺伊吉祥物 · 生成提示词与上传说明

当前内置吉祥物是一个 **Q 版小女孩**(黑色长发、碎刘海、圆脸大眼、浅蓝耳机与星星发饰、粉色小兔睡衣),
原型来自一张生活照,经卡通化重绘,不包含真人照片。她不是静态图:后台跑任务时会低头写作业,
头部能独立点头 / 歪头 / 摇头 / 抬头(身体不动),空闲时还会随机摸头、转身、伸懒腰、招手、眨眼,
听话 / 说话 / 开心各有动作。

下面给了 4 个方向的备选形象,以及可以直接粘到 **豆包 / 即梦 / 通义万相** 等平台的提示词。
生成后,在 App 里「设置 › 吉祥物 › 使用自定义吉祥物图片 › 选择图片」上传即可,所有用吉祥物的地方都会换成你这张图。
自定义图片仍会保留浮动 / 倾斜 / 转身等整体动作,也会跟着做点头 / 歪头 / 摇头 / 抬头的头部动作,
但不会叠加内置形象的手臂和书桌。

## 统一规格要求(生成时务必遵守)

- **画幅**:正方形 `1024 × 1024`(或 1:1)。
- **背景**:**透明背景**,不要加底色、不要加文字水印、不要带边框。(少数平台不支持透明,就生成纯白/纯浅蓝背景,再自行去底。)
- **主体**:居中、占画面 70%~85%、全身或半身均可,**不要露出半截身子被裁掉**。
- **配色**:沿用诺伊品牌蓝 `#2A9DFF`(主色)、浅蓝 `#EAF6FF`(高光)、深蓝灰 `#20303A`(描边/眼睛)。
- **风格**:扁平 / 轻拟物、干净、可爱但专业,**不要写实照片、不要 3D 写实、不要恐怖谷**。
- **不要文字**:图里不要出现「诺伊」「Nuoyi」「Mika」等任何字。

> 平台差异:豆包 / 即梦偏中文提示词,通义万相中英文都行。下面每个方向都给了「中文」和「English」两套,
> 直接复制对应平台语言的那段即可。把 `主体描述` 换成你选的方向。

## 生成后怎么用

1. 在平台上生成,挑一张满意的,**下载成 PNG**(务必透明背景)。
2. 打开诺伊 App → **设置 › 吉祥物**。
3. 打开「使用自定义吉祥物图片」开关 → 从相册 / 文件里选那张 PNG。
4. 欢迎页、Logo、关于页、聊天页头像、语音/通话页都会立刻换成你的图。
5. 想换回内置形象:同一页点「恢复默认」。

> 注意:启动器图标(桌面上的 App 图标)是系统自适应图标,运行时不能换图。
> 如果你也想换桌面图标,把生成的图导出成 `ic_mascot` 矢量或 PNG,替换 `app/src/main/res/drawable/ic_mascot.xml`
> (foreground)后重新打包即可。

## 不满意?微调提示词的小技巧

- 太复杂 → 删掉修饰词,只留「主体 + 颜色 + 透明背景 + 正方形」。
- 不像 AI → 加「天线 / 科技光环 / 蓝色发光」。
- 太恐怖 → 加「扁平插画风、可爱、大圆眼、无写实」。
- 被裁切 → 加「居中、全身入镜、四周留白」。
- 想换风格 → 把上面四个方向的主语互换着试。

## 内置形象:按真人照片做 Q 版小女孩

内置小女孩是以一张生活照为原型重绘的 **Q 版卡通形象**,不是照片、也没有把原图打进包里。
生成后做了白底去除,导出为 `app/src/main/res/drawable-nodpi/nuoyi_girl.png`(512×512 透明 PNG);
桌面启动图标是手绘矢量 `app/src/main/res/drawable/ic_mascot.xml`,状态栏小图标是 `ic_notification.xml`。

想换成另一张照片,可以直接把照片作为参考图交给支持图生图的模型,用这类提示词:

```
以参考照片里的小女孩为原型,重新画成可爱的 Q 版扁平插画吉祥物(不是照片、不是写实):
保留她的发型、发色、脸型、神态和衣服主色,但把五官卡通化、简化,不要还原真实面部细节,
不要画照片里的房间或背景。半身正面,圆脸大眼带白色高光,浅粉白色圆领上衣,
加一副浅蓝色小耳机和一枚蓝色小星星发饰作为 AI 助手元素。
扁平可爱插画风,柔和深色描边,品牌蓝 #2A9DFF 点缀,透明背景,正方形 1024×1024,
居中完整入镜,四周留白,无文字无水印,不要写实照片、不要 3D 渲染。
```

生成图若是白底,需要按连通区域去底(注意半身像贴着下边缘,不能从底部中央开始填充,
否则衣服里的浅色会被挖掉),再缩小到 512 放进 `drawable-nodpi`。

### 动作与 App 状态

动画绘制在 `app/src/main/java/com/nuoyi/agent/ui/theme/Mascot.kt`,由 `MascotMood` 驱动:

| 状态 | 什么时候 | 身体 / 手臂 | 头部 |
| --- | --- | --- | --- |
| `Thinking` | 后台有任务在跑 | 低头写作业:桌面、纸、铅笔,手臂上下书写,纸上笔画逐渐长出 | 微垂,随书写轻轻点动 |
| `Idle` | 平时 | 每 1.5~2.9 秒随机换一个:呼吸、摸头、转一转、伸懒腰打哈欠、招手、眨眼 | 同期随机:点头、歪头、摇头、抬头张望;摸头时手跟着脑袋偏 |
| `Listening` | 在听 | 手放耳边,耳机旁一圈圈声波 | 侧过头把耳朵凑近声源 |
| `Speaking` | 在说 | 嘴张合、小幅手势 | 连续点头 |
| `Happy` | 完成 / 开心 | 蹦跳、双手举起、星星闪 | 左右轻晃、微微抬起 |

### 头部动作怎么实现的

`Mascot.kt` 的 `drawMascotBands()` 把整张插画按 24 / 48 条水平带绘制,每条带按它所在的高度取
`headWeight(y)` 权重(头顶到眼睛为 1,到肩 / 领口平滑降到 0),施加水平位移、垂直位移和横向压缩。
条带的目标高度由「变换后的上下边界取整再相减」得到,相邻带严格首尾相接,所以点头 / 抬头时
不会露出 1px 细缝或出现横向条纹。

这样做的好处是**不拆图、不裁剪**:没有接缝、白边、双影,也不需要额外的图片资源;
自定义上传的任意图片同样会有头部动作。眨眼、小嘴、耳机声波按所在高度的权重一起偏移,
不会留在原位。

边界:这是 2D 局部形变,能表现点头 / 歪头 / 左右摇头 / 抬头,但**不是 3D 转头**,不会看到侧脸;
小尺寸(灵动胶囊 30~40dp)只能看清整体起伏,细节在设置页 120dp 大图里最清楚。

自定义图片仍会跟随浮动 / 倾斜 / 转身与头部动作,但不会叠加手臂和书桌,避免和别的形象打架。
点「设置 › 吉祥物 › 恢复」随时回到内置小女孩。
