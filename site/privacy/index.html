隐私说明

你的手机，你的数据

这份说明讲清楚诺伊把什么留在本机、什么会发给谁、以及哪些动作需要你先同意。它不是法律文件，具体以应用内实际权限与开源代码为准。

留在本机的内容

  • 会话记录、任务记录、设置、唤醒词（个人版）、你填入的模型 Key 与各服务商额度状态，保存在应用私有数据目录。
  • 检查更新的结果、自动更新下载的安装包，也只存在应用自己的外部专属目录，安装完成或取消后清理。
  • 诊断信息不会自动上传：需要你在「关于 → 反馈问题 → 复制诊断信息」里主动复制，再自行决定是否贴到 Issues。

卸载应用会一并删除这些本机数据；更换设备不会自动同步。

会发出的网络请求

  • 模型请求：发往你在设置里配置的服务商。请求内容取决于任务本身，可能包含对话文字、你提供的文本；当任务需要模型理解屏幕时，可能包含屏幕上的文字或画面描述。发送前请确认你所用服务商的数据处理条款。
  • 网页访问：任务要求打开某个网页时，会像浏览器一样访问该站点。
  • 更新检查：只请求官网版本清单与其仓库镜像；下载安装包时访问自有 GitHub Releases 附件。这些请求不携带你的会话内容或设备标识清单。
问「诺伊你是谁」这类身份问题由本地代码直接回答，不发网络请求、不消耗额度。额度路由也只使用官方公开免费档与你自己的 Key，不向第三方共享额度服务发请求。

麦克风、语音与屏幕

  • 公版不含常驻热词代码，只有你通过系统语音入口或应用内按钮主动发起时才使用麦克风。
  • 个人版的本地常驻热词需要你明确开启并授权麦克风；热词模型在本机运行，不上传音频流，随时可关闭。
  • 识别与播报为半双工：播报时关麦，避免录到自己的声音；确认词命中才会继续执行敏感动作。
  • 后台屏幕的画面理解优先在本机完成；只有任务确实需要模型判断时，相关文字或画面描述才会随模型请求发往你配置的服务商。

权限与最小化

麦克风、通知、无障碍/辅助功能与系统调试权限都按需申请，可以单独关闭；关闭后相应能力会明确提示不可用，不会在后台偷偷重试。敏感动作（发消息、下单、删除等）需要你二次确认后才执行。

安装包完整性

App 内更新只接受官网与自有仓库的 HTTPS 附件地址，下载后校验大小、SHA-256、包名、版本与签名证书；签名不一致会拒绝安装。下载页公布每个安装包的摘要与证书指纹，便于人工核对。
