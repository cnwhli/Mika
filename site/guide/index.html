上手指南

从安装到真正免手

按下面顺序做一遍就能用。公版走系统数字助手入口，个人版多一步本地热词设置；两者的差别在版本对比里写清楚了。

一、安装与授权

  1. 到 下载页 取对应 APK，核对页面上的 SHA-256 后安装（Android 11 及以上）。
  2. 首次打开时按界面提示授予麦克风与通知权限；语音播报、识别与二次确认都需要它们。
  3. 涉及在后台屏幕操作其它应用的能力，会提示开启无障碍 / 辅助功能；不开启时相关能力不可用，其它能力照常。
  4. 在系统「设置 → 应用 → 默认应用 → 数字助手应用」中选择诺伊，之后就能从系统语音入口叫起。
不要把从别处拿到的 APK 覆盖安装到诺伊上。App 会校验包名、版本与签名证书，签名不同的包一律拒绝；系统安装器也会再拦一次。

二、语音唤起

公版

唤醒词固定为「诺伊」，不可自定义，也不含常驻热词代码。通过系统数字助手入口（长按电源键、系统语音助手、App Actions）叫起后，直接说要办的事。

个人版

在应用内「语音设置」里可以改唤醒词并开启本地常驻热词。热词模型只在本机运行，服务需要你明确授权麦克风；随时可以关掉，关掉后回到系统助手入口的方式。

说话与确认

  • 识别与播报采用半双工：诺伊说话时会关麦，不会把自己的播报当成你的指令。
  • 发消息、下单、删除等敏感动作会复述一遍并等你确认，明确的肯定/否定词才会继续。
  • 任务运行中也能插话改方向或叫停；问「你是谁」不会打断正在做的事。

三、身份问答

无论打字、语音、通知回复、定时任务，还是任务中途插话，只要问「诺伊你是谁」，都会由本地代码直接回答：

我是李万禧的女儿，数字女儿

这条应答不经过模型、不消耗额度、不发起网络请求，也不会被品牌名与唤醒词同名的分词问题影响。

四、模型与额度

  • 在设置里填入你自己的服务商 Key，Key 保存在本机。
  • 额度路由只使用服务商官方公开的免费档与你自己的 Key；不内置、不借用任何来路不明的共享额度。
  • 遇到 429 / 402 / 额度耗尽会自动给该候选降温并切换，冷却结束后自愈重试；所有候选都不可用时明确告知，而不是静默失败。
  • 把网络请求发往哪家服务商由你的配置决定，详见 隐私说明。

五、自动化执行能力的前提

让诺伊「替你点开其它 App、按屏幕上的按钮操作」，需要设备提供系统 shell 级别的执行权限。当前可用路径包括：设备已 root、通过无线调试 / USB 调试启动的 shell 会话，或厂商开放的同等级通道。

没有上述权限时，对话、语音问答、网页阅读、知识整理等能力仍可用；自动化执行会明确提示缺少权限，不会假装执行成功。面向所有普通用户的「无 root 降级执行路径」仍在开发中，本站不会把它描述成已具备的能力。

六、更新与校验

App 每次打开读取官网版本清单（公版 / 个人版），官网不可达时读仓库里同一份清单的镜像。下载前只允许官网与自有仓库的 HTTPS 附件路径；下载后校验大小、SHA-256、包名、版本和签名证书。

自动更新是否自动下载，由「设置 → 自动更新」开关决定，默认关闭；下载完成也只会提示你安装，系统安装器仍会要求你确认。

七、遇到问题

  • 叫不起来：确认已设为默认数字助手应用，麦克风权限已开；个人版再检查热词服务是否在运行。
  • 识别不准：说话前等提示音，尽量短句；嘈杂环境可以改用打字入口。
  • 更新一直提示失败：检查能否访问官网与 GitHub；也可以在关于页手动检查更新，或到 Releases 手动下载。
  • 要反馈：关于页可以复制诊断信息（不会自动上传），贴到 Issues 前请先删掉个人信息。
