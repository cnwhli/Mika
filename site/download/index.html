选择安装包

普通用户选「公版 · 全架构」。设备是 arm64（绝大多数现代安卓机）可以选体积更小的专用包。个人版仅供自用侧载。

正在读取版本清单…… 若长时间没有内容，请前往 GitHub Releases 下载。

公版与个人版包名不同，可以并排安装；但请用同一版本系列的更新包覆盖安装，不要拿另一版的 APK 当更新，App 会拒绝包名不符的安装包。

核对签名与校验值

本版使用自有证书签名。签名证书 SHA-256 指纹：

97:BF:C9:61:14:CA:00:E7:87:51:10:FB:CF:CD:4A:90:A4:68:99:AC:00:64:BC:B7:B5:96:3C:6D:85:E1:2B:06

下载完成后，在电脑上核对文件摘要（把文件名换成你下载的那一个）：

shasum -a 256 Nuoyi-v0.1.42-public.apk
apksigner verify --print-certs Nuoyi-v0.1.42-public.apk

摘要应与卡片上的 SHA-256 一致，证书指纹应与上面一致。App 内更新会自动完成大小、摘要、包名、版本与签名证书校验，任何一项不符都会拒绝安装。

系统要求：Android 11（API 30）及以上。安装包为正式签名 release 包，未开启调试；首次侧载需要在系统设置里允许「安装未知应用」。

安装与首次设置

  1. 下载对应 APK，核对 SHA-256 后点击安装。
  2. 打开诺伊，按界面提示授予麦克风、通知与必要的辅助功能权限。
  3. 在系统「默认数字助手应用」里选择诺伊，即可从系统语音入口叫起；个人版还可在应用内设置自定义唤醒词并开启本地热词。
  4. 需要使用「替你操作其它 App」的自动化能力时，按 使用指南 开启系统调试权限；未开启时相应能力会明确提示，不会静默失败。

更新渠道

官网是唯一对外发布渠道。App 每次打开会读取版本清单，官网暂时不可达时改读仓库里同一份清单的镜像；安装包文件始终来自自有 GitHub Releases。

  • 公版清单：api/latest.json
  • 个人版清单：api/latest-personal.json
  • 镜像：raw.githubusercontent.com/cnwhli/nuoyi/main/site/api/
  • 发布页：GitHub Releases

两个版本各用各的清单，避免个人版被公版 APK 覆盖。清单里的 APK 直链只允许落在官网下载目录或自有仓库的发布附件路径，其它域名的链接一律拒绝。
